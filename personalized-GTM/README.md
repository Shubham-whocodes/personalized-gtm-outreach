# Personalized Reachout

## **Zamp · ASA Case Study · PS-3 (GTM)** — automated prospect research and personalised outreach drafting with a human review gate.

## What it does


| Stage        | What happens                                                       |
| ------------ | ------------------------------------------------------------------ |
| **Identify** | Public search + proposed match; you confirm before research runs   |
| **Research** | Three areas: background, company news, recruiting context          |
| **Draft**    | One angle + short email for the **case-study recruiting platform** |
| **Review**   | Evidence, edits, regenerate, confirm — **no auto-send**            |
